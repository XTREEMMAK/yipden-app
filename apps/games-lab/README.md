# Games Lab

Static SvelteKit and Capacitor development host. Realm is the default profile. Games load only
when Play is pressed. The initial players are lifecycle scaffolds; supplied HTML prototypes are
separate optional references.

See [game development](../../docs/games-development.md) for browser commands, APK builds and
the existing download-server workflow. The creator editor and native live-page bridge are later
production work, not part of this testing app.
